README // ADMIN CONTROL MANUAL

01 — PURPOSE

A MAP-এর configuration এখান থেকেই পরিচালনা করা যাবে। User login information, Hack.chat link, Admin boxes এবং information password এক জায়গা থেকে পরিবর্তন করা যাবে।

02 — AUTO PASSWORD

Login page প্রতিবার নতুন করে load হলে নতুন 8-character unique Auto Password তৈরি হয়। Login screen-এ প্রদর্শিত password-টিই সেই page-এর জন্য valid password। Refresh করলে আগের password আর valid থাকবে না।

03 — HACK.CHAT LINK

নিচের Hack.chat Group Link field-এ room link লিখে SAVE SETTINGS চাপো। এরপর Dashboard-এর CONNECT TO ADMIN থেকে verification code পূরণ করলে saved link open হবে। প্রয়োজন হলে একইভাবে নতুন link save করা যাবে।

04 — ADMIN INFORMATION

Dashboard-এর 5টি Admin Box-এর নাম ও বড় information text এখান থেকে edit করা যাবে। Dashboard-এ information দেখার জন্য Information-view password লাগবে।

05 — IMPORTANT

এই version browser localStorage ব্যবহার করে। তাই settings একই browser/device-এ persist করবে; এটি real server-side lifetime security নয়। Multi-device বা সত্যিকারের secure control-এর জন্য Firebase/backend authentication প্রয়োজন।
